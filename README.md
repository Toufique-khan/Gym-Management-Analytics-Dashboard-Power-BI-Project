# 🏋️ Gym Management Analytics Dashboard | Power BI Project

An interactive Power BI dashboard built to analyze gym operations, member activity, revenue trends, and business performance.

This project focuses on transforming raw gym membership and financial data into actionable business insights that help gym owners make smarter decisions.

---

# 🚀 Project Overview

Most gym systems only track workouts and memberships.

This dashboard goes beyond that by answering real business questions like:
- Who are the most valuable members?
- Which users are close to churning?
- Is the gym actually profitable?
- Which age group is most active?
- How are revenue and expenses trending?

The dashboard combines business analytics, member insights, financial tracking, and interactive reporting into one centralized system.
